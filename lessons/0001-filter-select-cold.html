Lesson 0001 · DataFrame API

filter + select, cold

One skill: keep rows, pick columns, type it without looking. This is the spine of almost every pipeline edit at work.

Win: From a blank cell, write a chain that filters then selects — using col — without opening docs.

1. Knowledge (keep tiny)

A DataFrame is a distributed table of named columns. Transforms return a new DataFrame; they do not mutate the old one.

Two ops you type constantly:

  • filter(condition) — keep rows. where is an alias for the same method.
  • select(*cols) — pick / project columns (and expressions).

Column expressions come from pyspark.sql.functions.col. Prefer col("amount") > 100 over string SQL for pipeline code you will compose. 

from pyspark.sql import SparkSession
from pyspark.sql.functions import col

spark = SparkSession.builder.getOrCreate()
df = spark.createDataFrame(
    [(1, "a", 50), (2, "b", 200), (3, "a", 150)],
    "id INT, region STRING, amount INT",
)

out = (
    df.filter(col("amount") > 100)
      .select("id", "region", col("amount"))
)
# out rows: (2, b, 200), (3, a, 150)

Three ways to name a column (same idea)

df.select("amount")           # string name
df.select(col("amount"))      # Column object (compose-friendly)
df.select(df.amount)          # attribute — breaks if name has dots/spaces

Pipeline habit: strings for plain picks, col(...) when you compare or build expressions. Official quickstart shows the same create → transform flow: Quickstart: DataFrame.
