1. Imports you need for the drills

from pyspark.sql.functions import col, lit, when

2. withColumn — add or replace

df.withColumn(name, column_expr) returns a new DataFrame.

  • If name is new → column appended (usually last).
  • If name already exists → that column is replaced; other columns stay.
# NEW column amount2 (ex1)
df.withColumn("amount2", col("amount") * 2)

# REPLACE amount in place (ex2)
df.withColumn("amount", col("amount") + 10)

Official note: many chained withColumn calls build a fat plan; for lots of new columns prefer one select(...). For these drills, single withColumn is fine.

3. withColumnRenamed — rename only

df.withColumnRenamed(old, new) renames; does not change values or drop other columns. 

# amount → spend (ex3)
df.withColumnRenamed("amount", "spend")
# columns become: id, region, spend, status

Diff from lesson 0001: col("amount").alias("spend") inside select projects (you list what to keep). withColumnRenamed keeps the full frame, just renames one field.

4. drop — remove columns

df.drop("status") removes one or more columns by name. 

# drop status (ex4)
df.drop("status")
# remaining: id, region, amount

5. cast — change type

col("amount").cast("double") returns a Column of the new type. String type names like "double", "int", "string" work. 

# amount_d as double (ex5) — select form
df.select(
    "id",
    "amount",
    col("amount").cast("double").alias("amount_d"),
)

# same idea via withColumn then select
df.withColumn("amount_d", col("amount").cast("double")).select(
    "id", "amount", "amount_d"
)

6. lit — constant on every row

Python values are not Columns. Wrap constants with lit(...). 

# version = "v1" for every row (ex6)
df.select("id", lit("v1").alias("version"))

# or
df.withColumn("version", lit("v1")).select("id", "version")

7. when / otherwise — if/else column

when(condition, value) + .otherwise(value). Without otherwise, unmatched rows are null. 

# band high/low (ex7)
df.select(
    "id",
    "amount",
    when(col("amount") > 100, "high").otherwise("low").alias("band"),
)

# withColumn form also fine:
df.withColumn(
    "band",
    when(col("amount") > 100, "high").otherwise("low"),
).select("id", "amount", "band")

Chain more branches: when(...).when(...).otherwise(...).

8. Chain for pipelines (ex8)

Same as work code: filter rows → enrich column → project.

# east only, tax = amount * 0.1, project id/amount/tax
(
    df.filter(col("region") == "east")
      .withColumn("tax", col("amount") * 0.1)
      .select("id", "amount", "tax")
)

amount * 0.1 yields floating values (e.g. 5.0). That is what the checker expects for tax.

9. Full toy session (read once, then close)

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, lit, when

spark = SparkSession.builder.getOrCreate()
df = spark.createDataFrame(
    [(1, "east", 50, "active"), (2, "west", 200, "closed")],
    "id INT, region STRING, amount INT, status STRING",
)

df.withColumn("amount2", col("amount") * 2).show()
df.withColumnRenamed("amount", "spend").show()
df.drop("status").show()
df.select("id", lit("v1").alias("version")).show()
df.select(
    "id",
    when(col("amount") > 100, "high").otherwise("low").alias("band"),
).show()
