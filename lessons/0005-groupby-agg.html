Lesson 0005 · DataFrame API

groupBy + agg

Collapse many rows into one per key. Last core piece for cold-writing work pipelines: filter → join → groupBy → agg.

Win: Cold-write df.groupBy(...).agg(...) with clean aliases, multi-key groups, and post-agg filter (“having”).

2. Mental model

groupBy does not return a normal DataFrame yet — it returns GroupedData. You must aggregate (count/sum/agg/…) to get a DataFrame again. 

df.groupBy("region")           # GroupedData — not show()-able usefully
   .agg(sum("amount").alias("total"))  # DataFrame again

3. Signature

df.groupBy(*cols) · alias groupby 

df.groupBy("region")
df.groupBy("region", "status")
df.groupBy(col("region"))

Then either a convenience method or .agg(...): 

from pyspark.sql.functions import col, sum, count, avg, max, min

# convenience
df.groupBy("region").count()              # cols: region, count
df.groupBy("region").sum("amount")        # cols: region, sum(amount)

# preferred at work: agg + alias (clean names)
df.groupBy("region").agg(
    count("*").alias("n"),
    sum("amount").alias("total"),
    avg("amount").alias("avg_amt"),
    max("amount").alias("hi"),
)

Default names like sum(amount) are legal but ugly in pipelines. Prefer .alias("total") every time you care about the contract.

4. Core patterns (solution kit)

ex1 — count rows per region

orders.groupBy("region").count()
# east 3, west 2, north 1
# columns: region, count

ex2 — sum with default name

orders.groupBy("region").sum("amount")
# columns: region, sum(amount)
# east 300, west 280, north 300

ex3 — avg with alias

(
    orders.groupBy("region")
          .agg(avg("amount").alias("avg_amount"))
)
# east 100.0, west 140.0, north 300.0

ex4 — several aggs at once

(
    orders.groupBy("region").agg(
        count("*").alias("n"),
        sum("amount").alias("total"),
        max("amount").alias("hi"),
    )
)
# east: n=3 total=300 hi=150
# west: n=2 total=280 hi=200
# north: n=1 total=300 hi=300

ex5 — two keys

orders.groupBy("region", "status").count()
# each (region, status) pair is its own group

ex6 — filter first (pre-agg)

(
    orders.filter(col("status") == "open")
          .groupBy("region")
          .agg(sum("amount").alias("open_total"))
)
# open only: east 250, west 200, north 300

ex7 — filter after agg (SQL HAVING)

(
    orders.groupBy("region")
          .agg(sum("amount").alias("total"))
          .filter(col("total") > 250)
)
# total > 280 → east 300, north 300 (west 280 drops)

Rule: conditions on raw columns go before groupBy. Conditions on aggregates go after (filter the result).

ex8 — join then aggregate

# sales: order_id, cust_id, amount
# customers: cust_id, name
(
    sales.join(customers, "cust_id", "inner")
         .groupBy("name")
         .agg(sum("amount").alias("spend"), count("*").alias("orders"))
)

5. Imports for drills

from pyspark.sql.functions import col, sum, count, avg, max, min

sum/max/min shadow Python builtins — fine inside Spark code; or use from pyspark.sql import functions as F and F.sum(...).

6. Work mental model

  • One row per group key(s) after agg.
  • Need clean names for next join/select → .alias inside agg.
  • Pre-agg filter shrinks input; post-agg filter keeps big groups only.
  • Mission chain: filter → join → groupBy → agg → select.
