3. Knowledge → each exercise

ex1 — open + high + join

(
    orders.filter((col("status") == "open") & (col("amount") >= 100))
          .join(customers, "cust_id", "inner")
          .select("order_id", "name", "amount", "region")
)
# 1 Alice, 2 Bob, 6 Carol

ex2 — left join + when + tax

(
    orders.join(customers, "cust_id", "left")
          .filter(col("amount") >= 100)
          .withColumn("band", when(col("amount") >= 150, "high").otherwise("low"))
          .withColumn("tax", col("amount") * 0.1)
          .select("order_id", "name", "amount", "band", "tax")
)

ex3 — open → join → sum by region

(
    orders.filter(col("status") == "open")
          .join(customers, "cust_id", "inner")
          .groupBy("region")
          .agg(sum("amount").alias("open_total"))
)
# east 450 (100+300+50), west 250 — orphan open dropped by inner

ex4 — join → multi agg by tier

(
    orders.join(customers, "cust_id", "inner")
          .groupBy("tier")
          .agg(sum("amount").alias("spend"), count("*").alias("n"))
)
# gold 490 / 4, silver 400 / 2

ex5 — join → filter → agg → having

(
    orders.join(customers, "cust_id", "inner")
          .filter(col("region") == "east")
          .groupBy("name")
          .agg(sum("amount").alias("spend"))
          .filter(col("spend") > 200)
)
# Carol 350 only (Alice 140 fails having)

ex6 — left join customers + count(order_id)

(
    customers.join(orders, "cust_id", "left")
             .groupBy("name")
             .agg(count(col("order_id")).alias("n_orders"))
)
# Dan → 0  (count skips null order_id; count("*") would wrongly give 1)

Trap: left-side “how many matches?” needs count(col("right_key")), not count("*").

ex7 — filter amount → join → gold → sum

(
    orders.filter(col("amount") >= 100)
          .join(customers, "cust_id", "inner")
          .filter(col("tier") == "gold")
          .groupBy("name")
          .agg(sum("amount").alias("spend"))
)
# Alice 100, Carol 300

ex8 — mission chain

(
    orders.filter(col("status") == "open")
          .join(customers, "cust_id", "inner")
          .withColumn(
              "fee",
              when(col("tier") == "gold", lit(0.0)).otherwise(col("amount") * 0.05),
          )
          .groupBy("name")
          .agg(count("*").alias("orders"), sum("fee").alias("fee_total"))
)
# Alice 1 / 0.0, Bob 1 / 12.5, Carol 2 / 0.0

4. Order habits (work)

  • Filter early when the predicate is on raw rows.
  • Join for dimension fields, then groupBy business key.
  • Agg aliases before post-filter (having) or next join.
  • Left + count: null-aware count on the right key.
