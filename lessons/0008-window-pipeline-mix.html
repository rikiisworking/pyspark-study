3. Knowledge → each exercise

ex1 — open → join → row_number per region

w = Window.partitionBy("region").orderBy(col("amount").desc(), col("order_id"))
(
    orders.filter(col("status") == "open")
          .join(customers, "cust_id", "inner")
          .withColumn("rn", row_number().over(w))
          .select("order_id", "name", "region", "amount", "rn")
)
# east: 6/300 rn1, 8/200 rn2, 1/100 rn3, 7/50 rn4
# west: 2/250 rn1, 9/100 rn2

ex2 — top-1 open per region

# same w as ex1, then filter rn == 1; drop rn from select
# east Carol 300, west Bob 250

ex3 — lag amount per name (all statuses)

w = Window.partitionBy("name").orderBy("day")
(
    orders.join(customers, "cust_id", "inner")
          .withColumn("prev", lag("amount").over(w))
          .select("order_id", "name", "day", "amount", "prev")
)
# Alice: 100→null, 40→100, 200→40

ex4 — open running sum per region by day

w = Window.partitionBy("region").orderBy("day")
(
    orders.filter(col("status") == "open")
          .join(customers, "cust_id", "inner")
          .withColumn("running", sum("amount").over(w))
          .select("order_id", "name", "region", "day", "amount", "running")
)
# east: 100 → 400 → 450 → 650

ex5 — top amount per tier (rank)

w = Window.partitionBy("tier").orderBy(col("amount").desc())
(
    orders.join(customers, "cust_id", "inner")
          .withColumn("r", rank().over(w))
          .filter(col("r") == 1)
          .select("order_id", "name", "tier", "amount")
)
# gold Carol 300, silver Bob 250

ex6 — amount ≥ 100 → dense_rank per region

w = Window.partitionBy("region").orderBy(col("amount").desc())
(
    orders.filter(col("amount") >= 100)
          .join(customers, "cust_id", "inner")
          .withColumn("d", dense_rank().over(w))
          .select("order_id", "name", "region", "amount", "d")
)
# includes Bob closed 150; drops Carol open 50

ex7 — open → lag + delta per name

w = Window.partitionBy("name").orderBy("day")
(
    orders.filter(col("status") == "open")
          .join(customers, "cust_id", "inner")
          .withColumn("prev", lag("amount").over(w))
          .withColumn("delta", col("amount") - col("prev"))
          .select("order_id", "name", "day", "amount", "prev", "delta")
)
# Bob open: 250 then 100 → delta -150; first day delta null

ex8 — top-2 open per region

# row_number like ex1, filter rn <= 2
# east 6+8, west 2+9

4. Order habits (work)

  • Filter status/amount before window when the peer set should ignore those rows.
  • Join for name/region/tier, then partitionBy business key.
  • Top-N: row_number + filter — not groupBy + max then rejoin (unless you need it).
  • amount - lag: first row null; fine — filter nulls later if report needs.
