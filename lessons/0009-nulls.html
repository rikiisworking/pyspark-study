Nulls

Detect, drop, fill, and coalesce missing values — every work pipeline hits these.

Win: Cold-write isNull / isNotNull, na.drop, na.fill, coalesce, and null-aware when.

1. Toy data (same as drills)

orders
  id | region | amount | status
   1 | east   |    100 | open
   2 | east   |   null | open
   3 | west   |     50 | null
   4 | null   |   null | closed
   5 | west   |      0 | open      ← 0 is not null
   6 | east   |    200 | closed

2. Mental model

Spark SQL uses three-valued logic: true / false / unknown (null). Comparisons with null yield null (treated as not-true in filter). So status == "open" drops rows where status is null — not a bug. 

from pyspark.sql.functions import col, lit, coalesce, when

col("amount").isNull()
col("amount").isNotNull()
# WRONG: col("amount") == None   # does not mean isNull

df.na.drop(subset=["amount"])           # alias: dropna
df.na.fill({"amount": 0})               # alias: fillna
df.withColumn("r", coalesce(col("region"), lit("unknown")))

Docs: isNull · DataFrame.na · coalesce

3. Core patterns (solution kit)

ex1 — keep null amounts

orders.filter(col("amount").isNull())
# ids 2, 4

ex2 — keep non-null amounts

orders.filter(col("amount").isNotNull())
# ids 1, 3, 5, 6  (amount 0 stays)

ex3 — equality filter drops null status

orders.filter(col("status") == "open")
# ids 1, 2, 5 — not id 3 (status null → predicate null → dropped)

ex4 — drop if amount or status null

orders.na.drop(subset=["amount", "status"])
# keeps 1, 5, 6

ex5 — fill amount nulls with 0

orders.na.fill({"amount": 0})
# id2 amount 0, id4 amount 0; other cols unchanged

ex6 — coalesce region

(
    orders.withColumn(
        "region_filled",
        coalesce(col("region"), lit("unknown")),
    ).select("id", "region", "region_filled")
)
# id4 → unknown

ex7 — flag missing amount

(
    orders.select(
        "id",
        "amount",
        when(col("amount").isNull(), "missing")
          .otherwise("present")
          .alias("flag"),
    )
)
# id5 amount 0 → present

ex8 — open or null status

orders.filter(
    col("status").isNull() | (col("status") == "open")
)
# ids 1, 2, 3, 5

4. Traps (work)

  • col("x") == None / Python is None on a Column — not how you test null. Use isNull().
  • 0 and "" are values, not null.
  • na.fill(0) fills numeric nulls only; strings need a string fill or a dict per column.
  • Null-safe equality exists: col("a").eqNullSafe(col("b")) (SQL <=>) — for joins/filters where null = null should match.
