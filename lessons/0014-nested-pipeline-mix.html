1. Toolbox (all you need)

from pyspark.sql import Window
from pyspark.sql.functions import (
    col, from_json, explode, explode_outer,
    coalesce, lit, sum, row_number,
)

schema = "user_id INT, amount INT, status STRING, tags ARRAY<STRING>"

# parse early, then treat fields as normal columns
df.withColumn("p", from_json(col("raw"), schema))
df.select("event_id", col("p.user_id").alias("user_id"), col("p.amount").alias("amount"))

# join dim table on parsed key
.join(customers, col("user_id") == col("cust_id"), "inner")  # or "left"

# arrays
explode(col("p.tags"))
explode_outer(col("p.tags"))

# nulls / agg / window / I/O (you already know these)
.na.fill({"amount": 0})
.groupBy("name").agg(sum("amount").alias("total"))
Window.partitionBy("user_id").orderBy(col("amount").desc(), col("event_id"))
.write.mode("overwrite").parquet(path)
spark.read.parquet(path)

4. Traps (work)

  • Parse early, then alias flat columns before join/window — fewer p. headaches.
  • Join key: user_id (parsed) vs cust_id (dim). Column join, not string equality of names alone if names differ.
  • explode before join multiplies dim rows — usually explode then join, or join then explode deliberately.
  • Fill before sum if null amounts should count as 0 (ex5, ex7).
  • Top-N: drop null amounts before window if null must not win (ex6).
