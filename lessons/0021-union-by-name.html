Lesson 0021 · stretch (new API)

Stack frames by name

Two extracts, one report. union seats columns left-to-right. Work files shuffle names — use unionByName.

Win: Cold-write union, unionByName, allowMissingColumns=True, distinct. Finish 19_union.py.

0. Map: knowledge → exercise

ex1  union same column order          → keeps both row 4s
ex2  union shuffled seats             → amount lands in order_id
ex3  unionByName shuffled             → names line up

1. Toy data

east(order_id, amount, status)
  1  100  open
  2   50  open
  3  200  closed
  4   80  open

west_aligned(order_id, amount, status)     # same seats
  4   80  open     ← twin of east 4
  5   40  open
  6  150  closed

west_shuf(amount, order_id, status)        # same names, swapped seats
  80  4  open
  40  5  open
  150 6  closed

west_extra(..., region)                    # one more column
  7  90  open  north

2. Position vs name

union is SQL UNION ALL: “resolves columns by position (not by name).” No automatic dedup — add distinct if you want a set. unionAll is an alias of union. 

east.union(west_aligned)     # fine when seats match
east.union(west_shuf)        # types match, *meanings* swap
# west amount 80 sits in east's order_id seat → (80, 4, open)

unionByName “resolving columns by name.” Default allowMissingColumns=False (3.1+): extra / missing name → raise. True: fill the hole with null. Left column order wins; new names append. 

east.unionByName(west_shuf)
east.unionByName(west_extra, allowMissingColumns=True)
# order_id, amount, status, region
# east rows → region null; west_extra 7 / north

3. After you have one frame

# still a DataFrame — filter / select as usual
east.unionByName(west_aligned).filter(col("status") == "open")

# tag source *before* the stack (work ticket)
east.withColumn("src", lit("east")).unionByName(
    west_aligned.withColumn("src", lit("west"))
)

4. Knowledge → each exercise

ex1 — aligned union

east.union(west_aligned)
# 7 rows. Two (4, 80, open). Names stay east's.

ex2 — the seat trap

east.union(west_shuf)    # NOT unionByName
# last three rows: (80, 4, open), (40, 5, open), (150, 6, closed)

ex3 — same files, by name

east.unionByName(west_shuf)
# last three: (4, 80, open), (5, 40, open), (6, 150, closed)

ex4 — set, not bag

east.unionByName(west_aligned).distinct()
# one (4, 80, open)

ex5 — schema drift

east.unionByName(west_extra, allowMissingColumns=True)
# 4 east + row 7. region null on east.

ex6 — chain

east.unionByName(west_shuf).unionByName(west_extra, allowMissingColumns=True)
# 4 + 3 + 1. Two row-4s. region only on 7.

ex7 — then filter

# open only. Both row 4s stay (east + west).

ex8 — tag source

# columns order_id, src. 4 is east *and* west.

5. Traps (work)

  • union = position. Same types + shuffled names silently swap meaning.
  • Default work call: unionByName. Add allowMissingColumns=True when a file grew a column.
  • Neither call distincts. Twin extracts keep twin rows until distinct.
  • unionAll is not SQL-vs-union. It is the same as union.
  • Tag src on each side before the stack, or you cannot tell which file a row came from.
